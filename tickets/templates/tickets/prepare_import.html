GoOut Import

Since GoOut does not provide an export containing all the required columns (QR code/Ticket number, First Name, Last Name, and Company Name), you can merge two separate files and link them by Order Number.

Please use the following exports from the GoOut administration:
"Přehled prodeje – transakce položkové.xlsx"
"Event name – odbavení - Odbavení.csv"

Click on "Merge Files" to combine the documents (right join). Once merged, the file will download automatically. We recommend reviewing the merged file before importing.
