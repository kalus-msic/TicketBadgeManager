Supported CSV Format:
  • Tested with ti.to export in UTF-8 and goout files.
  • The file can use either a comma (,) or semicolon (;) as a delimiter. We recommend using the semicolon (;).
  • Required columns (if any required field is missing in a row, that row will be skipped during import; you must include at least one of the following variants):
    • Ticket Number: "Číslo vstupenky", "Ticket Number", or "Unique Ticket URL"
    • First Name: "Jméno", "Jméno_x", or "Ticket First Name"
    • Last Name: "Příjmení", "Příjmení_x", or "Ticket Last Name"
  • Optional columns (you can include one of the following variants, if applicable):
    • Company Name: "Firma", "Field1", or "Ticket Company Name"
    • Event Name: "Akce", "Akce_x", or "Event"
    • Email: "Email", "E-mail", or "Ticket Email"
